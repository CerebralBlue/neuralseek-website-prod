NeuralWorks

Un assistant de travail créé à partir d'agents que vous contrôlez

NeuralWorks aide votre équipe pour les réunions, les e-mails, les documents et les mises à jour de vos systèmes. Chaque tâche s'exécute sur des agents mAIstro que vous pouvez ouvrir et modifier.

Ce qu'il fait

Une aide pour le travail de tous les jours

Chaque tâche est un ensemble d'agents, et vous configurez ce que fait chaque ensemble.

  • Réunions

    Préparer les réunions de votre agenda et assurer le suivi de celles qui ont eu lieu.

  • E-mails

    Trier ce qui arrive, faire ressortir ce qui vous attend et rédiger des réponses que vous envoyez vous-même.

  • Documents

    Rédiger et modifier des documents à partir de vos données, dans l'éditeur intégré ou exportés au format que vous utilisez.

  • Mises à jour dans vos systèmes métier

    Transformer une demande en langage courant en mise à jour dans les systèmes de votre organisation, comme un ticket, un enregistrement ou un message.

Là où vous travaillez

Tous vos agents sur un seul écran

L'écran Agents regroupe les agents selon leur moment d'exécution, avant ou après une réunion. Chacun a son propre interrupteur et un bouton Test.

Chaque ligne est un agent : ce qu'il fait, s'il s'exécute seul et la connexion dans laquelle il écrit. Activez ceux que vous voulez.

Créé à partir d'agents

Chaque tâche est un agent que vous pouvez ouvrir

Chaque fonction de NeuralWorks est un agent mAIstro. Vous pouvez lire son code de template, le modifier dans l'éditeur visuel et décider quand il s'exécute.

Chacune de ces fonctionnalités est une fonctionnalité standard de mAIstro. NeuralWorks les assemble pour une journée de travail.

  • L'ouvrir, le modifier

    Chargez un agent dans l'éditeur, modifiez-le et enregistrez-le sous un nom, comme tout workflow créé par votre équipe.

    Voir les workflows d'agents

  • Le planifier

    Agent Scheduler exécute un agent aux minutes, heures, jours et mois que vous fixez, pour que les tâches récurrentes se fassent sans que personne ne les lance.

    En savoir plus sur Agent Scheduler (en anglais)

  • Exécuté quand vous le décidez

    Un interrupteur sur chaque agent décide s'il s'exécute seul. Les autres s'exécutent quand vous les appelez. Sous un niveau de confiance que vous fixez, un agent de secours peut prévenir une équipe ou ouvrir un ticket.

    Voir comment les agents s'exécutent

  • Protégé dès l'entrée

    La protection contre l'injection de prompt, un filtre de langage grossier et le masquage des données personnelles sont des nœuds qu'un agent exécute avant que le modèle ne voie l'entrée.

    Voir les garde-fous

Ce que voit la revue de sécurité

Une sécurité que votre RSSI peut vérifier

Un assistant de travail accède à votre agenda, à votre messagerie, à vos documents et à vos systèmes métier. NeuralWorks s'exécute sur la plateforme NeuralSeek et en hérite les contrôles.

Ces contrôles viennent de la plateforme NeuralSeek et s'appliquent à chaque agent NeuralWorks.

  • Où il s'exécute

    Il s'exécute là où s'exécute la plateforme : en SaaS, dans votre compte cloud, sur votre propre cluster, ou dans un environnement entièrement isolé, sans connexion à Internet.

    Voir où vos données peuvent résider

  • Le modèle de votre choix

    Choisissez le modèle qu'exigent vos contrats et changez-le dans la configuration, sans rien reconstruire.

    Voir comment il est déployé

  • Données sensibles

    NeuralSeek détecte et masque les données personnelles avant l'appel au modèle, à l'aide de motifs intégrés et des vôtres.

    Voir les garde-fous

  • Une trace de chaque exécution

    Chaque exécution est enregistrée étape par étape, pour que votre équipe puisse voir exactement ce qu'a fait un agent.

    Voir ce qui est enregistré
