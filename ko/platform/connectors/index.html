커넥터

사용 중인 시스템에 에이전트를 연결합니다.

커넥터는 모두 노드입니다. 다른 단계와 똑같이 에이전트에 추가하며, 같은 가드레일과 감사 추적이 적용됩니다.

기본 제공 커넥터

이미 쓰는 도구를 위한 커넥터

각 그룹은 에이전트 에디터에 있는 노드 모음입니다. 어떤 배포 방식에서도 같은 노드를 사용합니다.

  • 데이터베이스·데이터 웨어하우스

    기록을 보관하는 시스템을 워크플로의 한 단계로 조회하고, 결과를 다음 노드에 전달합니다. 데이터는 원래 위치에 그대로 있습니다.

  • 검색·지식·거버넌스 시스템

    조직에서 이미 운영하는 검색 및 지식 플랫폼을 소스로 사용합니다. 다른 소스와 같은 근거 확인이 적용됩니다.

  • 클라우드 스토리지·콘텐츠 관리

    정책, 계약서, 절차서를 보관하는 스토리지와 문서 라이브러리를 읽고 쓸 수 있습니다. 생성한 문서를 다시 저장하는 것도 포함됩니다.

  • 개발·협업 도구

    이슈 트래커, 코드 호스팅, 보드, 팀 메시징을 지원합니다. 답변과 업데이트가 팀이 평소 일하는 곳에 도착합니다.

  • 업무용 생산성 제품군

    메일, 캘린더, 문서, 파일을 지원합니다. 에이전트가 직원이 이미 열어 둔 도구에서 작업을 준비하고 저장합니다.

  • 이메일·파일 전송

    자사 SMTP 서버로 메일을 보내고, SFTP로 파일을 일정에 맞춰 전송합니다.

  • 웹 검색·가져오기

    공개 웹 소스를 의도적으로 추가한 단계로 검색하고 가져옵니다. 결과는 다른 외부 콘텐츠와 마찬가지로 유입 시점에 검사합니다.

  • 감사 로그 전송 대상

    감사 스트림을 오브젝트 스토리지, Splunk, Datadog 또는 자사 수집기로 보냅니다. 기록을 다른 보안 데이터와 함께 보관할 수 있습니다.

노드 라이브러리

시스템마다 하나의 노드

각 카드는 에이전트 에디터의 노드입니다. 캔버스에 놓고 쿼리와 연결 정보를 입력하면 다음 노드가 결과를 읽을 수 있습니다.

MySQLMySQL 데이터베이스에 연결해 SQL 쿼리를 실행하고, 행을 일반 문장 또는 CSV로 반환합니다. 다음 노드가 그대로 사용할 수 있습니다.

OracleOracle 데이터베이스에 연결해 SQL 쿼리를 실행하고, 데이터를 문장 또는 CSV로 반환합니다.

BigQueryJSON 자격 증명으로 인증해 BigQuery 프로젝트에 SQL 쿼리를 실행하고, 데이터를 문장 또는 CSV로 반환합니다.

RedshiftRedshift 웨어하우스에 연결해 SQL 쿼리를 실행하고, 데이터를 문장 또는 CSV로 반환합니다.

Neo4jBolt 연결로 Neo4j 그래프에 Cypher 쿼리를 실행하고, 데이터를 문장 또는 CSV로 반환합니다.

CassandraCassandra 데이터베이스에 쿼리를 실행하고 데이터를 워크플로에 반환합니다.

Watson Discovery작업과 페이로드를 Watson Discovery API로 보냅니다. URL과 키를 비워 두면 Seek 지식 베이스로 이미 설정한 Discovery 인스턴스를 재사용합니다.

Box ListBox 폴더의 내용을 나열하고, 그 목록을 워크플로에 반환합니다.

Search TrelloAPI 키와 토큰으로 Trello에 연결해 검색 쿼리를 실행하고, 일치한 결과를 문장 또는 JSON으로 반환합니다.

Google Calendar - SearchGoogle Calendar를 검색하고, 일치한 일정을 워크플로에 반환합니다.

Google Drive - Read폴더를 공유한 서비스 계정으로 Google Drive 폴더에서 제목 또는 ID로 문서를 읽습니다.

Azure Blob List ContainersAzure Blob Storage 계정의 컨테이너를 나열하고, 그 목록을 워크플로에 반환합니다.

그 밖의 시스템

다른 어떤 시스템에도 연결

기본 제공 노드가 없는 시스템도 다음 방법으로 빠르게 연결할 수 있습니다.

  • REST 노드

    HTTP API가 있는 시스템이라면 하나의 단계로 호출할 수 있습니다. URL, 헤더, 본문, 작업은 노드에서 설정하고, 자격 증명은 Configure 탭에 보관한 시크릿에서 가져옵니다.

  • MCP로 사용하는 에이전트

    에이전트는 MCP 도구로 제공되므로 팀이 운영하는 어떤 MCP 클라이언트에서도 호출할 수 있습니다. 같은 가드레일과 실행 기록이 적용됩니다.

  • 카드로 설정하는 모델

    모델도 커넥터와 같은 방식으로 설정합니다. 담당할 기능에 체크한 카드 하나입니다. 모델을 바꿔도 그 위에 구축한 것은 그대로 동작합니다.

시스템 연결에 대한 질문

AI 에이전트를 기간 시스템에 연결하기 전에 보안팀이 확인하는 내용입니다.

  1. 01

    시스템을 연결하면 데이터는 어디로 가나요?

    +

    커넥터는 NeuralSeek가 실행되는 곳에서 실행됩니다. 자사 환경이라면 사내 네트워크 안입니다. 모델도 자체 호스팅하면 모든 호출이 사내에서 끝납니다.

  2. 02

    자격 증명은 어디에 보관되나요?

    +

    Configure 탭에 이름이 붙은 시크릿으로 보관됩니다. 워크플로는 시크릿을 이름으로 참조하며 값은 표시되지 않습니다. 에디터의 메뉴에서 삽입합니다.

  3. 03

    에이전트는 시스템을 읽기만 하나요, 쓰기도 할 수 있나요?

    +

    쓰기도 가능하며, 같은 노드를 사용합니다. 각 단계가 보내고 받은 내용은 실행 기록에 남습니다. 저장한 에이전트는 API 요청이나 고객이 설정한 일정으로 호출될 때만 실행됩니다.
