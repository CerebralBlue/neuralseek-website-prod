NeuralWorks

직접 통제하는 에이전트로 만든 워크스페이스 어시스턴트

NeuralWorks는 회의, 이메일, 문서, 시스템 업데이트에서 팀을 돕습니다. 모든 작업은 직접 열어 수정할 수 있는 mAIstro 에이전트로 실행됩니다.

데모 요청하기에이전트 구축 방법 살펴보기

하는 일

평소 업무를 돕습니다

작업마다 에이전트 모음이 있으며, 각 모음이 하는 일은 직접 설정합니다.

  • 회의

    캘린더에 있는 회의를 준비하고, 끝난 회의는 후속 조치를 챙깁니다.

  • 이메일

    도착한 메일을 분류하고, 직접 봐야 할 메일을 골라내며, 보낼 답장의 초안을 작성합니다.

  • 문서

    자사 데이터로 문서를 작성하고 수정합니다. 기본 에디터에서 작업하거나 쓰는 형식으로 내보낼 수 있습니다.

  • 업무 시스템 업데이트

    자연어로 한 요청을 조직이 쓰는 시스템의 업데이트로 바꿉니다. 티켓, 레코드, 메시지 등이 해당합니다.

작업하는 곳

모든 에이전트를 한 화면에서

Agents 화면은 에이전트를 실행 시점인 회의 전과 회의 후로 묶어 보여 줍니다. 에이전트마다 스위치와 Test 버튼이 있습니다.

각 행이 에이전트 하나입니다. 하는 일, 자동 실행 여부, 결과를 기록할 연결 대상이 표시됩니다. 필요한 에이전트의 스위치를 켭니다.

에이전트로 구성

모든 작업이 열어 볼 수 있는 에이전트

NeuralWorks의 기능은 모두 mAIstro 에이전트입니다. 템플릿 코드를 읽고, 비주얼 에디터에서 수정하고, 실행 시점을 정할 수 있습니다.

이 기능은 모두 mAIstro의 표준 기능입니다. NeuralWorks는 이 기능들을 하루 업무에 맞게 조립한 모습입니다.

  • 열어서 수정

    에이전트를 에디터에 불러와 수정하고 이름을 붙여 저장합니다. 팀이 직접 만드는 워크플로와 똑같습니다.

    에이전트 워크플로 살펴보기

  • 일정에 따라 실행

    Agent Scheduler는 분, 시, 일, 월로 정한 시각에 에이전트를 실행하므로 반복 작업이 누가 시작하지 않아도 진행됩니다.

    Agent Scheduler 자세히 알아보기

  • 정한 대로 실행

    에이전트마다 있는 스위치가 자동 실행 여부를 정합니다. 나머지는 호출할 때 실행됩니다. 설정한 신뢰도 수준 아래에서는 폴백이 팀에 알리거나 이슈를 만들 수 있습니다.

    에이전트 실행 방식 살펴보기

  • 입력 단계에서 보호

    프롬프트 인젝션 방어, 비속어 필터, 개인정보 마스킹은 모델이 입력을 보기 전에 에이전트가 실행하는 노드입니다.
