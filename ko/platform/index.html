플랫폼

신뢰할 수 있는 답변과 AI 에이전트를 하나의 플랫폼에서.

회사 데이터를 정확한 답변과 업무를 처리하는 AI 에이전트로 바꿉니다. 가드레일과 로그가 기본으로 포함됩니다. 먼저 SaaS로 시작하거나 자체 인프라에서 운영할 수 있습니다.

작동 방식

처음부터 기본 내장

가드레일, 모델 선택, 배포 옵션이 기본으로 제공됩니다. 켜고 필요에 맞게 조정합니다.

  • 모든 호출에 가드레일 적용

    기본 제공 가드레일이 모든 질문과 답변을 검사합니다. 채팅 창, API 호출, 예약된 에이전트에 같은 규칙이 적용됩니다.

  • 원하는 모델 사용

    모델을 하나 또는 여러 개 추가하면 NeuralSeek가 부하를 나눠 처리합니다. 모델마다 맡을 작업을 고릅니다. 데이터, 가드레일, 앱은 그대로 유지됩니다.

  • 필요한 곳에서 운영

    SaaS를 쓰거나, 자사 클라우드 계정, OpenShift 클러스터, 인터넷과 완전히 분리된 자체 하드웨어에서 운영합니다. 가드레일과 기능은 어디서나 같습니다.

구성 요소

AI 구축에 필요한 모든 것

각 구성 요소는 서로 맞물려 동작합니다. 답변에 설정한 가드레일은 에이전트가 그 답변을 사용할 때도, 어떤 모델이 답하든, 어디에서 실행되든 똑같이 적용됩니다.

  • Seek: 자사 데이터 기반 답변

    자사 문서에서 가져온 답변에 신뢰도와 커버리지 점수를 매기고 근거 구절을 강조해 보여 줍니다. 고급 검색과 승인된 답변의 캐시가 기본으로 포함됩니다.

    Seek 살펴보기
    console › seek

  • mAIstro: AI 에이전트

    비주얼 에디터로, 또는 NeuralSeek의 템플릿 언어인 NTL 코드로 여러 단계의 에이전트를 구축합니다. 단계마다 모델을 고르고, 결과에 따라 분기하고, 단계를 병렬로 실행하며, 에이전트가 스스로 실행되도록 일정을 설정합니다.

    mAIstro 살펴보기
    console › maistro › agent editor

  • 가드레일

    수백 개의 가드레일이 들어오는 질문을 검사하고 나가는 답변을 점검합니다. 주제별로 설정하고, 자사 에이전트에 레드 팀 테스트를 언제든 실행할 수 있습니다.

    가드레일 살펴보기
    console › neural config › guardrails

  • 거버넌스

    실행된 모든 것의 기록입니다. 시간에 따른 답변 점수, 소요 시간이 담긴 에이전트 실행, 롤백할 수 있는 설정 변경 로그를 제공합니다.

    거버넌스 살펴보기
    console › governance › overview

  • 커넥터

    데이터베이스, 파일 저장소, 검색, 문서 라이브러리를 위한 기본 제공 노드입니다. 각 노드는 에이전트의 한 단계이며, 모든 에이전트는 REST나 MCP 도구로 호출할 수 있습니다.

    커넥터 살펴보기
    console › maistro › function library

  • 원하는 모델 사용

    플랫폼과 모델을 골라 LLM을 추가하면 그 모델이 지원하는 기능을 미리 확인할 수 있습니다. 여러 개를 추가하면 NeuralSeek가 부하를 나눠 처리합니다. 모델 교체는 설정 변경입니다.

    모델 옵션 살펴보기
    console › neural config › add an llm

  • 배포 방식

    위의 모든 것을 담은 하나의 컨테이너입니다. SaaS로 시작하거나, AWS, Azure, IBM Cloud 마켓플레이스에서 구매하거나, IBM Fusion에서 실행하거나, 자체 OpenShift 또는 Kubernetes에 설치합니다. 필요하면 완전히 분리된 환경으로 운영할 수도 있습니다.

자주 묻는 질문

시작하기 전에 팀이 흔히 묻는 내용입니다.

  1. 01

    기본적인 RAG 구성과 무엇이 다른가요?

    +

    검색은 일부일 뿐입니다. NeuralSeek는 모든 호출에 검사를 더하고, 몇 달 뒤에도 찾아볼 수 있는 답변별 전체 기록을 남기며, 모델을 바꿔도 계속 동작하는 에이전트와 자사 환경 안의 배포를 제공합니다.

  2. 02

    특정 모델 업체에 종속되나요?

    +

    아니요. 모델마다 맡을 작업을 고르고, 에이전트 단계마다 모델을 선택하며, API 호출 한 건에서 모델을 재정의할 수도 있습니다. 어느 것을 바꾸든 설정 변경입니다.

  3. 03

    이미 모델 제공업체와 벡터 스토어가 있습니다. 어떻게 함께 쓰나요?

    +

    둘 위에서 동작합니다. 자사 제공업체 키를 쓰고 이미 운영하는 검색을 NeuralSeek에 지정합니다. NeuralSeek는 근거 확인, 가드레일, 에이전트, 전체 감사 추적을 더합니다.

오늘 NeuralSeek로 구축을 시작해 보세요.

온라인으로 가입해 2주 체험으로 시작하거나, 자사 클라우드에서 운영하는 방법을 NeuralSeek 전문가와 상담할 수도 있습니다.
