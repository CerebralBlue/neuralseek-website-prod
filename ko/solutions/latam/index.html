규제 대상 기관

규제 대상 기관을 위해 설계

은행, 신용협동조합, 공공 기관은 데이터가 어디에 있는지, 모델에 닿기 위해 국경을 넘는지, 검사관이 무엇을 보게 되는지, 모든 답변이 근거 문서로 추적되는지를 묻습니다. NeuralSeek는 이 네 가지에 모두 배포 방식으로 답합니다.

같은 통제 기능이 NeuralSeek SaaS를 포함한 모든 배포 방식에서 제공됩니다.

  • 주권

    자국 안에 남는 것은 무엇인지, 자체 모델 API 키나 자사 하드웨어의 오픈 모델로 모델 호출까지 어떻게 자국 안에 두는지 설명합니다.

    데이터 주권과 AI 주권

  • 답변, 가드레일, 감사, 데이터 위치

    추적 가능한 답변, 가드레일, 모든 답변의 기록, 데이터 위치에 대한 통제를 다루며, 금융 서비스와 헬스케어에 대해서는 더 자세한 내용이 있습니다.

    모든 솔루션

언어

질문한 언어로 답변

스페인어, 포르투갈어, 영어 답변이 검증된 하나의 지식 베이스에서 나오므로, 직원과 조합원은 어떤 언어로 물어도 같은 답변을 받습니다.

  • 스페인어, 포르투갈어, 영어 등

    지원 언어에는 영어, 스페인어, 포르투갈어와 함께 프랑스어, 독일어, 이탈리아어, 아랍어, 한국어, 중국어, 일본어 등이 포함됩니다. 하나의 지식 베이스로 모든 언어를 처리합니다.

  • 언어 자동 감지

    NeuralSeek는 각 질문의 언어를 감지해 그 언어로 답하며, 언어별 설정이 필요 없습니다. 영어로 작성된 콘텐츠라도 스페인어 질문에는 스페인어로 답합니다.

  • ‘Match Input’으로 더 많은 언어

    그 밖의 언어는 ‘Match Input’ 설정으로 지원합니다.

배포 방식

자사 클라우드나 데이터센터에서 운영

자사 클라우드 계정이나 데이터센터의 Kubernetes 또는 OpenShift에서 NeuralSeek를 운영하면 처리는 자국 안에 머뭅니다. NeuralSeek SaaS는 댈러스, 프랑크푸르트, 시드니에서 운영됩니다.

컨테이너는 배포한 리전에서 실행됩니다. NeuralSeek와 하위 처리자는 모두 고객 데이터를 모델 학습에 사용하지 않습니다.

  • NeuralSeek SaaS

    클라우드 마켓플레이스를 통해 구매해 바로 시작할 수 있습니다. 처리는 댈러스, 프랑크푸르트, 시드니 중 한 곳에서 이루어집니다.

    마켓플레이스 옵션

  • 자체 인프라 또는 클라우드 계정

    같은 플랫폼을 Kubernetes 또는 OpenShift 클러스터에 컨테이너로 설치해, 선택한 클라우드 리전, 온프레미스, 인터넷과 완전히 분리된 환경에서 운영합니다. 원하는 모델 제공업체나 자사 하드웨어의 오픈 모델을 사용할 수 있습니다.

    배포 방식 알아보기

일하는 방식

직접 찾아가 함께 구축합니다

대부분의 프로젝트는 방화벽 안에서 가치 검증(PoV)으로 시작합니다. 실제로 운영될 인프라에서 하나의 활용 사례를 검증합니다. 컨설팅 파트너가 NeuralSeek와 함께 프로젝트를 진행할 수도 있습니다.

  1. 01

    1단계

    직접 찾아갑니다

    하나의 활용 사례를 함께 정의합니다. 답변에 쓸 콘텐츠, 대상 사용자, 배포 방식, 성공 기준을 정합니다.

  2. 02

    2단계

    함께 구축합니다

    방화벽 안에서, 실제로 운영될 인프라에서 팀과 나란히 앉아 가치 검증을 구축합니다.

  3. 03

    3단계

    결과물은 고객의 것입니다

    구성, 지식 베이스, 애플리케이션은 고객이 보유한 라이선스 아래 고객의 것입니다.

파일럿 전에 나오는 질문

이 지역의 기관이 가장 먼저 묻는 질문에 간단히 답합니다.

  1. 01

    처리를 자국 안에 둘 수 있나요?

    +

    네. 자사 클라우드 계정, 데이터센터, 인터넷과 완전히 분리된 사이트의 Kubernetes 또는 OpenShift에서 NeuralSeek 컨테이너를 실행하면 됩니다. 검색, 오케스트레이션, 감사 추적도 함께 그곳에서 실행됩니다.

  2. 02

    모델에 닿으려면 질문이 국외로 나가야 하나요?

    +

    다른 곳에서 호스팅되는 모델을 선택했을 때만 그렇습니다. 나머지는 모두 배포 환경 안에서 실행됩니다. 자체 제공업체 API 키나 자사 하드웨어의 오픈 모델을 사용하면 모델 호출도 환경 안에 남습니다.

  3. 03

    콘텐츠는 영어인데, 조합원은 스페인어로 질문합니다.

    +

    하나의 지식 베이스로 둘 다 처리합니다. NeuralSeek는 질문의 언어를 감지해 그 언어로 답하며, 콘텐츠의 사본을 따로 둘 필요가 없습니다. 포르투갈어도 같은 방식으로 동작합니다.

오늘 NeuralSeek로 구축을 시작해 보세요.

온라인으로 가입해 2주 체험으로 시작하거나, 자사 클라우드에서 운영하는 방법을 NeuralSeek 전문가와 상담할 수도 있습니다.
