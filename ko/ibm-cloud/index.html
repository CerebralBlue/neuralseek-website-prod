NeuralSeek on IBM Cloud

NeuralSeek를 IBM Cloud 카탈로그에서 구매합니다. watsonx 모델, watsonx Assistant와 함께 SaaS로, 또는 자사 OpenShift에서 운영할 수 있습니다.

구매 방법

카탈로그에서 구매하거나 직접 운영

제품과 전문 서비스가 모두 IBM Cloud 카탈로그에 있습니다. 자사 OpenShift에서 컨테이너를 운영할 수도 있습니다.

구매 방식과 관계없이 모든 배포는 같은 기능을 제공합니다.

  • IBM Cloud 카탈로그의 제품

    이미 운영 중인 IBM Cloud 계정에서 카탈로그 항목이 연결하는 약관에 따라 NeuralSeek를 프로비저닝합니다.

    카탈로그 항목 열기

  • 같은 카탈로그의 전문 서비스

    온보딩, 교육, 구현 서비스를 소프트웨어와 같은 카탈로그와 조달 경로에서 시간 단위 묶음으로 구매합니다.

    서비스 항목 열기

  • 자사 OpenShift의 컨테이너

    같은 소프트웨어를 컨테이너 라이선스에 따라 선택한 계정, 네트워크, 리전의 OpenShift 또는 Kubernetes에 컨테이너로 설치합니다. 설정은 NeuralSeek 팀과 상담해 진행합니다.

IBM 네이티브 연동

NeuralSeek가 사용하는 IBM 서비스

기본 제공 연동입니다. 이미 운영 중인 watsonx, Discovery, Assistant 환경에 거버넌스가 적용된 애플리케이션 계층을 더합니다.

NeuralSeek

  • 모델 계층으로서의 watsonx.ai

    지원되는 모델 제공업체입니다. 설정할 때 watsonx 모델을 선택하거나 에이전트 단계마다 다른 모델을 선택할 수 있고, 나중에 구성에서 변경할 수 있습니다.

  • 지식 베이스로서의 Watson Discovery와 watsonx Discovery

    관련성 튜닝과 동적 필터 쿼리에 권장됩니다. 적합한 문서의 순위를 높이고, 사용자별로 볼 수 있는 범위로 쿼리를 제한합니다. watsonx Discovery는 벡터 검색과 하이브리드 검색을 추가합니다.

  • 가상 에이전트로서의 watsonx Assistant

    퀵스타트 템플릿이 폴백 검색을 추가합니다. Assistant가 질문에 답하지 못하면 NeuralSeek가 지식 베이스에서 답변합니다. 큐레이션한 답변은 Assistant로 내보낼 수 있으며, 출처가 바뀌면 플래그가 표시됩니다.

  • 에이전트 안에서 쓰는 watsonx.governance

    에이전트 단계에서 검색과 답변을 watsonx.governance에 기록하거나 원시 페이로드를 보내므로, IBM의 모델 기록과 NeuralSeek의 감사 추적이 같은 요청을 설명합니다.

에이전트 내부

모든 실행 안의 거버넌스

각 연동은 실행 안의 한 단계입니다. 단계마다 모델을 선택하고, 지식 베이스가 답변하며, 답변이 만들어지는 동안 거버넌스 호출이 이루어집니다.

모델 계층의 watsonx.ai

원하는 방식으로 watsonx.ai 모델 사용

구성에서 watsonx.ai 모델을 카드로 추가하고, 담당할 기능을 고르고, 원하면 다른 제공업체를 함께 추가합니다. 가격이나 모델이 바뀌면 구성만 업데이트하면 되고, 에이전트는 그대로 실행됩니다.

보안 검토 답변

보안 검토를 위한 간단한 답변입니다.

  1. 01

    데이터는 암호화되나요?

    +

    네, 전송 중과 저장 시 모두 암호화됩니다. 서비스로 들어오거나 서비스를 거치는 모든 데이터는 TLS로 암호화되고, 저장되는 모든 데이터도 암호화됩니다.

  2. 02

    고객 데이터가 무언가를 학습하는 데 사용되나요?

    +

    아니요. NeuralSeek와 하위 처리자는 모두 고객 데이터를 모델이나 시스템 학습에 사용하지 않으며, 생성된 답변은 고객의 소유입니다.

  3. 03

    요청에 포함된 개인정보는 어떻게 처리되나요?

    +

    개인정보로 감지된 콘텐츠는 설정한 방식(플래그 지정, 마스킹, 숨기기, 삭제)으로 처리됩니다. 맞춤형 답변을 위해 개인정보가 포함된 요청도 같은 방식으로 처리됩니다.
