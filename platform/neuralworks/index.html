A workspace assistant built from agents you control

NeuralWorks helps your team with meetings, email, documents and system updates. Each job runs on mAIstro agents you can open and edit.

Request a demoSee how agents are built

What it does

Help with the work of a normal day

Each job is a set of agents, and you configure what each set does.

  • Meetings

    Prepare for the meetings on your calendar and follow up on the ones that have happened.

  • Email

    Sort what arrives, surface what needs you, and draft replies for you to send.

  • Documents

    Draft and edit documents from your own data, in the built-in editor or exported to the format you work in.

  • Updates in your business systems

    Turn a plain-language request into an update in the systems your organization runs on, such as a ticket, a record or a message.

Where you work

All your agents on one screen

The Agents screen groups agents by when they run, before or after a meeting. Each one has its own switch and a Test button.

Each row is an agent: what it does, whether it runs on its own, and the connection it writes to. Switch on the ones you want.

Built from agents

Every job is an agent you can open

Each NeuralWorks function is a mAIstro agent. You can read its template code, edit it in the visual editor and decide when it runs.

Every one of these is a standard mAIstro feature. NeuralWorks is what they look like assembled into a working day.

  • Open it, edit it

    Load an agent into the editor, change it and save it by name, like any workflow your own team builds.

    See agent workflows

  • Run it on a schedule

    The Agent Scheduler runs an agent at the minutes, hours, days and months you set, so the recurring jobs happen without someone starting them.

    Read about the Agent Scheduler

  • Runs when you decide

    A switch on each agent decides whether it runs on its own. The rest run when you call them. Below a confidence level you set, a fallback can notify a team or open an issue.

    See how agents are run

  • Guarded on the way in

    Prompt-injection protection, a profanity filter and personal-data masking are nodes an agent runs before a model sees the input.

    See the guardrails

What the security review sees

Security your CISO can review

A workspace assistant works with your calendar, inbox, documents and business systems. NeuralWorks runs on the NeuralSeek platform and gets its controls.

These controls come from the NeuralSeek platform and apply to every NeuralWorks agent.

  • Where it runs

    It runs where the platform runs: as SaaS, in your own cloud tenant, on your own cluster, or fully air-gapped.

    See where your data is allowed to live

  • Your choice of model

    Pick the model your contracts require and change it in configuration, with no rebuild.

    See how it is deployed

  • Sensitive data

    Personal data is found and masked before the model call, using built-in patterns and your own.

    See the guardrails

  • A record of every run

    Every run is recorded step by step, so your team can inspect exactly what an agent did.

    See what is recorded
