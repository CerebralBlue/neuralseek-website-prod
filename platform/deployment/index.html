What's included

Everything in one container

Every part ships together, so there's nothing extra to install, run or buy later.

  • The model layer

    Use a commercial or open-weight model, from a provider or hosted on your own hardware. Swap it anytime without touching the rest.

  • Your data and retrieval

    Your knowledge base, search settings and accuracy checks, connected to your own documents and search tools.

  • Connectors and actions

    Ready-made connectors to your systems, plus REST for everything else. Credentials are stored as secrets.

  • Guardrails and audit

    Screening, PII masking, grounding checks and the audit trail, working the same way in every deployment.

  • Orchestration

    The editor where you build agents and the engine that runs them, so every new app runs in the same place.

Once it is running

Your environment, your controls

Run it in your own environment, and your existing security controls apply to it.

  • Runs under your existing controls

    Install it in an environment you have already approved and it runs under that environment's network controls, key management, logging and incident process.

Questions about deployment

What procurement and IT teams ask first.

  1. 01

    Do we get the same features on every cloud?

    +

    Yes. Our SaaS, the marketplace listings, the IBM Fusion appliance and your own cluster all run the same software. Deployments differ only in where they run and who manages them.

  2. 02

    Can it run with no internet connection?

    +

    Yes. Fully isolated on-prem is a standard option. An air-gapped install runs entirely on your infrastructure and stays fully under your control.

  3. 03

    What do we run ourselves on-prem?

    +

    Containers on Kubernetes or OpenShift, with the model layer, search, connectors, guardrails and agents inside. Secrets live in the configuration, audit logs go to your collector, and every settings change is logged.
