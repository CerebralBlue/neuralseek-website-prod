Native IBM integrations

The IBM services NeuralSeek uses

Built-in integrations. Add a governed application layer to the watsonx, Discovery and Assistant setup you already run.

NeuralSeek

  • watsonx.ai as the model layer

    A supported model provider. Pick a watsonx model at setup, or a different one for each step of an agent, and change it later in configuration.

  • Watson Discovery and watsonx Discovery as knowledge bases

    Recommended for relevance tuning and dynamic filter queries, which boost the right documents and limit a query to what each user may see. watsonx Discovery adds vector and hybrid search.

  • watsonx Assistant as the virtual agent

    A quick-start template adds fallback search: when the assistant has no answer for a question, NeuralSeek answers from your knowledge base. Curated answers export into the assistant and are flagged when sources change.

  • watsonx.governance from inside an agent

    An agent step logs a retrieval and its answer to watsonx.governance, or sends it a raw payload, so IBM's model record and NeuralSeek's audit trail describe the same request.

Inside an agent

Governance inside every run

Each integration is a step inside a run: a model is chosen per step, a knowledge base answers, and the governance call happens while the answer is produced.

watsonx.ai in the model layer

Use watsonx.ai models your way

Add a watsonx.ai model as a card in the configuration, choose the functions it serves, and add a second provider beside it if you like. When prices or models change, you update the configuration and your agents keep running.

Security review answers

Short answers for your security review.

  1. 01

    Is data encrypted?

    +

    Yes, in transit and at rest. Everything that flows to or through the service is encrypted over TLS, and everything stored is encrypted too.

  2. 02

    Is our data used to train anything?

    +

    No. Neither NeuralSeek nor any of its subprocessors use customer data to train models or systems, and generated answers belong to the customer.

  3. 03

    What happens to personal data in a request?

    +

    Content flagged as personal data is handled by the action you configure: flag, mask, hide or delete. Requests that carry personal data for a personalized answer are handled the same way.
