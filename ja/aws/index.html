AWSとのネイティブ連携

NeuralSeekが使うAWSのサービス

標準搭載の連携機能により、AWSから離れずにNeuralSeekを運用できます。

NeuralSeek

  • Amazon Bedrock・モデル

    対応しているモデルプロバイダーです。セットアップ時にBedrockのモデルを選び、エージェントのステップごとに別のモデルを選ぶこともできます。あとから設定で変更できます。

  • KendraとBedrock・ナレッジ

    マネージドなベクトル検索に対応したナレッジベースです。チャンク分割、エンベディング、インデックス作成はAWS側で行います。Kendraのフィルターで、各ユーザーが閲覧できる範囲にクエリを限定します。

  • Amazon Lex・仮想エージェント

    Lexのボットが質問に答えられないとき、NeuralSeekがナレッジベースから回答します。キュレーションした回答はLexにエクスポートでき、出典が変わるとフラグが付きます。

  • Amazon S3・ファイル

    エージェントのステップが、指定したバケット、リージョン、IAM認証情報を使って、バケットからファイルを読み込んだり書き戻したりします。

エージェントの中で

AWSのサービスをエージェントのステップに

AWSのサービスをステップとしてエージェントに追加し、サービス、認証情報、範囲を設定します。エンジニアがコンソールで目にするカードです。

S3 Read FileS3バケットのオブジェクトをワークフローに読み込みます。バケット、リージョン、IAMキーはノードで設定します。書き戻しはS3 Write Fileで行います。

RedshiftRedshiftのデータウェアハウスに接続してSQLクエリを実行し、データを文章またはCSVで返します。

モデル層のBedrock

Bedrockのモデルを思いどおりに

Bedrockのモデルを設定画面にカードとして追加し、担当させる機能を選びます。別のプロバイダーを並べて追加することもできます。料金やモデルが変わっても、設定を更新するだけでエージェントはそのまま動き続けます。

セキュリティ審査への回答

セキュリティ審査向けの簡潔な回答です。

  1. 01

    データは暗号化されますか？

    +

    はい。転送中も保存時も暗号化されます。サービスとやり取りするデータはすべてTLSで暗号化され、保存されるデータもすべて暗号化されます。

  2. 02

    自社のデータが学習に使われることはありますか？

    +

    ありません。NeuralSeekも再委託先も、顧客データをモデルやシステムの学習に使用しません。生成された回答はお客様に帰属します。

  3. 03

    リクエストに含まれる個人情報はどう扱われますか？

    +

    個人情報として検出された内容は、設定したアクション（フラグを付ける、マスキングする、非表示にする、削除する）に従って処理されます。パーソナライズされた回答のために個人情報を含むリクエストも、同じように処理されます。
