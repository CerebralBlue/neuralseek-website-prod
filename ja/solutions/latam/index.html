プラットフォーム

NeuralSeekでチームが得られるもの

どのモデルが回答しても、どこで動作しても、各機能は連携して動きます。

  • Seek：自社データに基づく回答

    自社の規程や製品ドキュメントに基づく回答に信頼度スコアを付け、出典となる箇所をハイライト表示します。

    Seekを見る
    console › seek

  • mAIstro：AIエージェント

    ビジュアルエディターでエージェントを構築します。エージェントは基幹システムを参照し、文書を作成し、案件を担当者に引き継ぎます。

    mAIstroを見る
    console › maistro › agent editor

  • ガードレール

    数百のガードレールを標準搭載。自社のルールに合わせてカスタマイズし、顧客が使う前に自社のエージェントをテストできます。

    ガードレールを見る
    console › neural config › guardrails

  • ガバナンス

    回答のスコア、エージェントの実行、すべての設定変更を記録し、監査人や規制当局から求められたときにすぐ提示できます。

    ガバナンスを見る
    console › governance › overview

  • 導入形態

    SaaSで始めることも、選んだリージョンの自社クラウドアカウントで運用することも、自社のデータセンターにインストールすることもできます。

規制対象の機関

規制対象の機関のために設計

銀行、信用組合、公的機関が尋ねるのは、データの保管場所、モデルに届くまでにデータが国境を越えるかどうか、検査官に何が見えるか、各回答を元の文書までたどれるか、の4点です。NeuralSeekは導入形態によって、そのすべてに応えます。

SaaSを含むすべての導入形態に、同じ管理機能が含まれます。

  • 主権

    国内にとどまるもの。そして、自社のモデルプロバイダーのAPIキーや自社ハードウェア上のオープンモデルを使い、モデルの呼び出しも国内にとどめる方法。

    データ主権とAI主権

  • 回答、ガードレール、監査、データの保管場所

    追跡できる回答、ガードレール、すべての回答の記録、データの保管場所の管理。金融サービスと医療については、さらに詳しくご紹介しています。

言語

質問と同じ言語で回答

スペイン語、ポルトガル語、英語の回答は、同じ検証済みのナレッジベースから生成されます。スタッフも組合員も、どの言語で尋ねても同じ回答を受け取れます。

  • スペイン語、ポルトガル語、英語など

    対応言語には、英語、スペイン語、ポルトガル語のほか、フランス語、ドイツ語、イタリア語、アラビア語、韓国語、中国語、日本語などがあります。1つのナレッジベースですべての言語に対応します。

  • 言語を自動で検出

    NeuralSeekは各質問の言語を検出し、その言語で回答します。言語ごとの設定は不要です。スペイン語の質問には、英語で書かれたコンテンツからでもスペイン語で回答します。

  • 「Match Input」でさらに多くの言語に対応

    そのほかの言語には、「Match Input」設定で対応します。

導入形態

自社のクラウドやデータセンターで運用

自社のクラウドアカウントやデータセンターで、KubernetesまたはOpenShift上にNeuralSeekを導入すれば、処理は国内にとどまります。SaaSはダラス、フランクフルト、シドニーで動作しています。

コンテナは、導入したリージョンで動作します。NeuralSeekもその再委託先も、顧客データをモデルのトレーニングに使用しません。

  • SaaS

    クラウドマーケットプレイスを通じて購入し、すぐに始められます。処理はダラス、フランクフルト、シドニーのいずれかで行われます。

    マーケットプレイスの選択肢

  • 自社のインフラまたはクラウドアカウント

    同じプラットフォームを、KubernetesまたはOpenShiftのクラスターにコンテナとして導入します。選んだクラウドリージョン、オンプレミス、インターネットから完全に隔離された環境で動作します。任意のモデルプロバイダー、または自社ハードウェア上のオープンモデルを使えます。

    導入の仕組み

進め方

現地に伺い、一緒に構築します

多くのプロジェクトは、ファイアウォール内での価値実証（PoV）から始まります。1つのユースケースを、実際に運用するインフラ上で検証します。お客様のコンサルティングパートナーが、NeuralSeekと一緒にプロジェクトを進めることもできます。

  1. 01

    フェーズ01

    現地に伺う

    1つのユースケースの範囲を一緒に決めます。回答の元になるコンテンツ、利用するユーザー、導入形態、成功の基準です。

  2. 02

    フェーズ02

    一緒に構築する

    ファイアウォール内での価値実証を、実際に運用するインフラ上で、お客様のチームと並んで構築します。

  3. 03

    フェーズ03

    お客様のものになる

    設定、ナレッジベース、アプリケーションはお客様のものです。ライセンスもお客様が保有します。

パイロット前のよくある質問

地域の機関が最初に尋ねることに、簡潔にお答えします。

  1. 01

    処理を国内にとどめられますか？

    +

    はい。NeuralSeekのコンテナを、自社のクラウドアカウント、データセンター、インターネットから完全に隔離された拠点で、KubernetesまたはOpenShift上で実行します。検索、オーケストレーション、監査証跡もそこで動作します。

  2. 02

    モデルに届くまでに、質問が国外に出る必要はありますか？

    +

    国外でホストされているモデルを選んだ場合に限ります。それ以外はすべて、お客様の導入環境で動作します。自社のプロバイダーのAPIキーや、自社ハードウェア上のオープンモデルを使えば、モデルの呼び出しも自社の環境にとどまります。

  3. 03

    コンテンツは英語ですが、組合員はスペイン語で質問します。

    +

    1つのナレッジベースで両方に対応します。NeuralSeekは質問の言語を検出してその言語で回答するため、コンテンツを別の言語で用意する必要はありません。ポルトガル語でも同じです。
