Conectores prontos

Conectores para as ferramentas que você já usa

Cada grupo é um conjunto de nós no editor de agentes. Os mesmos nós funcionam em todas as instalações do NeuralSeek.

  • Bancos de dados e data warehouses

    Consulte os sistemas que guardam seus registros como uma etapa de um fluxo de trabalho e passe o resultado para o próximo nó. Os dados ficam onde estão.

  • Sistemas de busca, conhecimento e governança

    Use como fonte as plataformas de busca e conhecimento que a sua organização já tem, com as mesmas verificações de fontes de qualquer outra.

  • Armazenamento em nuvem e gestão de conteúdo

    Leia e grave no armazenamento e nas bibliotecas de documentos que guardam suas políticas, contratos e procedimentos, inclusive para salvar de volta um documento gerado.

  • Ferramentas de desenvolvimento e colaboração

    Gerenciadores de tickets, hospedagem de código, quadros e mensagens da equipe, para que respostas e atualizações cheguem aonde sua equipe já trabalha.

  • Pacotes de produtividade para o trabalho

    E-mail, agendas, documentos e arquivos, para que um agente prepare e arquive o trabalho nas ferramentas que as pessoas já têm abertas.

  • E-mail e transferência de arquivos

    Envie e-mails pelo seu próprio servidor SMTP e mova arquivos por SFTP de forma programada.

  • Busca e recuperação na web

    Pesquise e obtenha fontes públicas da web como uma etapa que você adiciona de propósito. O NeuralSeek verifica os resultados na entrada, como qualquer outro conteúdo externo.

  • Destinos de auditoria

    Envie o fluxo de auditoria para armazenamento de objetos, Splunk, Datadog ou seu próprio coletor, para que o registro fique junto com o resto dos seus dados de segurança.

A biblioteca de nós

Um nó para cada sistema

Cada card é um nó no editor de agentes. Coloque-o na tela, preencha a consulta e a conexão, e o próximo nó pode ler o resultado.

MySQLConecta-se a um banco de dados MySQL, executa sua consulta SQL e retorna as linhas como frases simples ou como CSV para o próximo nó usar.

OracleConecta-se a um banco de dados Oracle, executa uma consulta SQL e retorna os dados como frases ou em CSV.

BigQueryExecuta uma consulta SQL em um projeto do BigQuery, com autenticação por uma credencial JSON, e retorna os dados como frases ou em CSV.

RedshiftConecta-se a um data warehouse do Redshift, executa uma consulta SQL e retorna os dados como frases ou em CSV.

Neo4jExecuta uma consulta Cypher em um grafo do Neo4j pela conexão Bolt e retorna os dados como frases ou em CSV.

CassandraExecuta uma consulta em um banco de dados Cassandra e retorna os dados para o fluxo de trabalho.

Watson DiscoveryEnvia uma operação e o payload dela para a API do Watson Discovery. Se a URL e a chave ficarem em branco, o nó reutiliza a instância do Discovery já configurada como base de conhecimento do Seek.

Box ListLista o conteúdo de uma pasta do Box e retorna a listagem para o fluxo de trabalho.

Search TrelloConecta-se ao Trello com uma chave de API e um token, executa uma busca e retorna os resultados como frases ou como JSON.

Google Calendar - SearchPesquisa em um Google Calendar e retorna os eventos correspondentes para o fluxo de trabalho.

Google Drive - ReadLê um documento de uma pasta do Google Drive pelo título ou pelo ID, usando uma conta de serviço com a qual a pasta foi compartilhada.

Azure Blob List ContainersLista os contêineres de uma conta do Azure Blob Storage e retorna a lista para o fluxo de trabalho.

Para todo o resto

Conecte qualquer outro sistema

Quando não há um nó pronto para um sistema, estas opções permitem que sua equipe o conecte rapidamente.

  • O nó REST

    Qualquer sistema com uma API HTTP pode ser uma etapa: URL, cabeçalhos, corpo e operação são definidos no nó, e as credenciais vêm dos segredos que você guarda na aba Configure.

  • Agentes via MCP

    Seus agentes ficam disponíveis como ferramentas MCP, então qualquer cliente MCP que sua equipe usa pode chamá-los, com os mesmos guardrails e o mesmo registro de execução.

  • Modelos como cards

    Um modelo é configurado do mesmo jeito que um conector: um card, com as funções que ele atende marcadas. Troque o modelo e tudo o que foi criado sobre ele continua funcionando.

Perguntas sobre como conectar seus sistemas

O que as equipes de segurança perguntam antes que agentes de IA cheguem aos sistemas centrais da empresa.

  1. 01

    Para onde vão nossos dados quando conectamos um sistema?

    +

    Um conector é executado onde o NeuralSeek é executado. No seu próprio ambiente, isso significa dentro da sua rede. Se você também hospedar o seu próprio modelo, todas as chamadas ficam dentro da sua organização.

  2. 02

    Onde ficam as credenciais?

    +

    Na aba Configure, como segredos com nome. Um fluxo de trabalho usa um segredo pelo nome, e o valor fica oculto. Você o insere por um menu do editor.

  3. 03

    Um agente pode gravar em um sistema, além de ler?

    +

    Sim, com os mesmos nós. O que cada etapa enviou e recebeu fica no registro de execução, e um agente salvo só é executado quando é chamado por uma solicitação à API ou por um agendamento que você define.
