Integrações nativas com o Azure

Os serviços do Azure que o NeuralSeek usa

Integrações incluídas no produto, que você configura no console.

NeuralSeek

  • Azure OpenAI como camada de modelos

    Um provedor de modelos compatível, com a família GPT. Escolha um modelo ao configurar o NeuralSeek, ou um diferente para cada etapa de um agente, e troque depois na configuração.

  • Azure AI Bot Service como agente virtual

    Quando o bot não tem resposta para uma pergunta, o NeuralSeek responde a partir da sua base de conhecimento. As respostas revisadas são exportadas para o bot, e o monitoramento de ida e volta as sinaliza quando os documentos de origem mudam.

  • SharePoint a partir de um agente

    Uma etapa do agente pode listar, baixar ou enviar arquivos em um site do SharePoint com as credenciais de tenant, site e cliente que você informar, para que seus documentos do SharePoint alimentem um fluxo de trabalho com governança.

  • As bases de conhecimento que você já usa

    ElasticSearch e OpenSearch para a busca de documentos, e Pinecone e Milvus para a busca vetorial, todos compatíveis na sua conta do Azure.

Dentro de um agente

Serviços da Microsoft como etapas de um agente

Adicione um serviço da Microsoft a um agente como uma etapa, defina as credenciais e o escopo, e cada execução fica registrada.

Azure Blob List ContainersLista os contêineres de uma conta do Azure Blob Storage e devolve a lista ao fluxo de trabalho.

SharePoint List FilesLista os arquivos de um site do SharePoint, com as credenciais de tenant, site e cliente definidas no nó. Outros nós relacionados baixam e enviam arquivos.

Email (Outlook)Envia e-mails pelo Outlook a partir de uma etapa do fluxo de trabalho, para que a resposta de um agente saia como mensagem.

Respostas para a revisão de segurança

Respostas curtas para a sua revisão de segurança.

  1. 01

    Os dados são criptografados?

    +

    Sim, em trânsito e em repouso. Tudo o que chega ao serviço ou passa por ele é criptografado com TLS, e tudo o que fica armazenado também é criptografado.

  2. 02

    Nossos dados são usados para treinar alguma coisa?

    +

    Não. Nem o NeuralSeek nem nenhum dos suboperadores dele usam dados de clientes para treinar modelos ou sistemas, e as respostas geradas pertencem ao cliente.

  3. 03

    O que acontece com os dados pessoais de uma solicitação?

    +

    O conteúdo identificado como dados pessoais recebe a ação que você configurar: sinalizar, mascarar, ocultar ou excluir. As solicitações que trazem dados pessoais para uma resposta personalizada recebem o mesmo tratamento.
