Integrações nativas com a AWS

Os serviços da AWS que o NeuralSeek usa

Integrações incluídas no produto, para você usar o NeuralSeek sem sair da AWS.

NeuralSeek

  • Amazon Bedrock · modelos

    Um provedor de modelos compatível. Escolha um modelo do Bedrock ao configurar o NeuralSeek, ou um diferente para cada etapa de um agente, e troque depois na configuração.

  • Kendra e Bedrock · conhecimento

    Bases de conhecimento compatíveis para busca vetorial gerenciada, com a segmentação, os embeddings e a indexação feitos pela AWS. Os filtros do Kendra limitam cada consulta ao que cada usuário pode ver.

  • Amazon Lex · agente virtual

    Quando um bot do Lex não tem resposta para uma pergunta, o NeuralSeek responde a partir da sua base de conhecimento. As respostas revisadas são exportadas para o Lex e sinalizadas quando as fontes mudam.

  • Amazon S3 · arquivos

    Uma etapa do agente lê um arquivo de um bucket ou grava um de volta, com o bucket, a região e as credenciais do IAM que você informar.

Dentro de um agente

Serviços da AWS como etapas de um agente

Adicione um serviço da AWS a um agente como uma etapa e defina o serviço, as credenciais e o escopo. Estes são os cards que sua equipe técnica vê no console.

S3 Read FileLê um objeto de um bucket do S3 para o fluxo de trabalho, com o bucket, a região e as chaves do IAM definidos no nó. O S3 Write File grava o objeto de volta.

RedshiftConecta-se a um data warehouse do Redshift, executa uma consulta SQL e devolve os dados como frases ou em CSV.

Bedrock na camada de modelos

Use os modelos do Bedrock do seu jeito

Adicione um modelo do Bedrock como um card na configuração, escolha as funções que ele atende e, se quiser, adicione outro provedor ao lado. Quando os preços ou os modelos mudam, você atualiza a configuração e seus agentes continuam funcionando.

Respostas para a revisão de segurança

Respostas curtas para a sua revisão de segurança.

  1. 01

    Os dados são criptografados?

    +

    Sim, em trânsito e em repouso. Tudo o que chega ao serviço ou passa por ele é criptografado com TLS, e tudo o que fica armazenado também é criptografado.

  2. 02

    Nossos dados são usados para treinar alguma coisa?

    +

    Não. Nem o NeuralSeek nem nenhum dos suboperadores dele usam dados de clientes para treinar modelos ou sistemas, e as respostas geradas pertencem ao cliente.

  3. 03

    O que acontece com os dados pessoais de uma solicitação?

    +

    O conteúdo identificado como dados pessoais recebe a ação que você configurar: sinalizar, mascarar, ocultar ou excluir. As solicitações que trazem dados pessoais para uma resposta personalizada recebem o mesmo tratamento.
