Een werkplekassistent gebouwd uit agents die je zelf beheert

NeuralWorks helpt je team met meetings, e-mail, documenten en systeemupdates. Elke taak draait op mAIstro-agents die je kunt openen en bewerken.

Wat het doet

Hulp bij het werk van een gewone dag

Elke taak is een set agents, en jij bepaalt wat elke set doet.

  • Meetings

    Bereid de meetings in je agenda voor en volg de meetings op die zijn geweest.

  • E-mail

    Sorteer wat binnenkomt, laat zien wat jouw aandacht nodig heeft en stel antwoorden op die je zelf verstuurt.

  • Documenten

    Stel documenten op en bewerk ze met je eigen data, in de ingebouwde editor of geëxporteerd naar het formaat waarin je werkt.

  • Updates in je bedrijfssystemen

    Zet een verzoek in gewone taal om in een update in de systemen waarop je organisatie draait, zoals een ticket, een record of een bericht.

Waar je werkt

Al je agents op één scherm

Het scherm Agents groepeert agents op het moment waarop ze draaien: vóór of na een meeting. Elk heeft een eigen schakelaar en een knop Test.

Elke rij is een agent: wat hij doet, of hij zelf draait en de verbinding waarnaar hij schrijft. Zet de agents aan die je wilt.

Gebouwd uit agents

Elke taak is een agent die je kunt openen

Elke functie van NeuralWorks is een mAIstro-agent. Je leest de templatecode, bewerkt hem in de visuele editor en bepaalt wanneer hij draait.

Elk van deze is een standaardfunctie van mAIstro. NeuralWorks laat zien hoe ze samen een werkdag vormen.

  • Open hem, bewerk hem

    Laad een agent in de editor, wijzig hem en sla hem op onder een naam, zoals elke workflow die je eigen team bouwt.

    Bekijk agent-workflows

  • Laat hem volgens schema draaien

    De Agent Scheduler draait een agent op de minuten, uren, dagen en maanden die je instelt, zodat terugkerende taken gebeuren zonder dat iemand ze start.

    Meer informatie over de Agent Scheduler

  • Draait wanneer jij beslist

    Een schakelaar op elke agent bepaalt of hij zelf draait. De rest draait wanneer je ze aanroept. Onder een betrouwbaarheidsniveau dat je instelt, kan een terugval een team waarschuwen of een ticket aanmaken.

    Bekijk hoe agents draaien

  • Beschermd aan de ingang

    Bescherming tegen prompt injection, een filter voor grof taalgebruik en maskering van persoonsgegevens zijn nodes die een agent uitvoert voordat een model de invoer ziet.

    Bekijk de guardrails

Wat de securityreview ziet

Beveiliging die je CISO kan beoordelen

Een werkplekassistent werkt met je agenda, inbox, documenten en bedrijfssystemen. NeuralWorks draait op het NeuralSeek-platform en krijgt zijn controles.

Deze controles komen van het NeuralSeek-platform en gelden voor elke NeuralWorks-agent.

  • Waar het draait

    Het draait waar het platform draait: als SaaS, in je eigen cloudomgeving, op je eigen cluster of volledig geïsoleerd.

    Bekijk waar je data mag staan

  • Je keuze van model

    Kies het model dat je contracten vereisen en wijzig het in de configuratie, zonder opnieuw te bouwen.

    Bekijk hoe het wordt geïmplementeerd

  • Gevoelige data

    NeuralSeek vindt en maskeert persoonsgegevens vóór de modelaanroep, met ingebouwde patronen en je eigen patronen.

    Bekijk de guardrails

  • Een log van elke run

    Elke run wordt stap voor stap vastgelegd, zodat je team precies kan nalopen wat een agent deed.
