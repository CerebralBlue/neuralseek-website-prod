連接器

讓代理程式連接 您使用的各種系統。

每個連接器都是一個節點。和其他步驟一樣加入代理程式即可，並適用相同的防護措施與稽核軌跡。

諮詢工程師了解如何建構代理程式

現成連接器

連接已在使用的工具

每個類別都是代理程式編輯器中的一組節點。在每種部署方式中，使用的都是相同的節點。

  • 資料庫與資料倉儲

    在工作流程中以一個步驟查詢存放記錄的系統，並將結果交給下一個節點。資料仍留在原處。

  • 搜尋、知識與治理系統

    將組織已在運作的搜尋與知識平台當作來源，並套用與其他來源相同的資料依據檢查。

  • 雲端儲存與內容管理

    讀取並寫入存放政策、合約與程序的儲存空間和文件庫，也包括將產生的文件存回。

  • 開發與協作工具

    問題追蹤、程式碼代管、看板與團隊訊息，讓回答與更新直接送到團隊平常工作的地方。

  • 職場生產力套件

    郵件、行事曆、文件與檔案，讓代理程式能在大家已開啟的工具中準備並歸檔工作。

  • 電子郵件與檔案傳輸

    透過自有 SMTP 伺服器寄送郵件，並依排程以 SFTP 傳輸檔案。

  • 網路搜尋與擷取

    搜尋並擷取公開網路來源，這是刻意加入的一個步驟。結果在進入時會和其他外部內容一樣受到篩檢。

  • 稽核目的地

    將稽核串流送到物件儲存、Splunk、Datadog 或自有收集器，讓記錄與其他安全資料放在一起。

節點庫

每個系統都有對應的節點

每張卡片都是代理程式編輯器中的一個節點。拖到畫布上，填入查詢與連線資訊，下一個節點就能讀取結果。

MySQL連接 MySQL 資料庫，執行 SQL 查詢，並將資料列以一般語句或 CSV 格式傳回，供下一個節點使用。

Oracle連接 Oracle 資料庫，執行 SQL 查詢，並將資料以語句或 CSV 格式傳回。

BigQuery以 JSON 憑證驗證身分，對 BigQuery 專案執行 SQL 查詢，並將資料以語句或 CSV 格式傳回。

Redshift連接 Redshift 資料倉儲，執行 SQL 查詢，並將資料以語句或 CSV 格式傳回。

Neo4j透過 Bolt 連線對 Neo4j 圖形資料庫執行 Cypher 查詢，並將資料以語句或 CSV 格式傳回。

Cassandra對 Cassandra 資料庫執行查詢，並將資料傳回工作流程。

Watson Discovery將操作及其 payload 送到 Watson Discovery API。URL 和金鑰留空時，會沿用已設為 Seek KnowledgeBase 的 Discovery 執行個體。

Box List列出 Box 資料夾的內容，並將清單傳回工作流程。

Search Trello以 API 金鑰和 token 連接 Trello，執行搜尋查詢，並將符合的項目以語句或 JSON 格式傳回。

Google Calendar - Search搜尋 Google 日曆，並將符合的項目傳回工作流程。

Google Drive - Read使用已獲資料夾共用權限的服務帳戶，依標題或 ID 讀取 Google Drive 資料夾中的文件。

Azure Blob List Containers列出 Azure Blob Storage 帳戶中的容器，並將清單傳回工作流程。

其他所有系統

連接任何其他系統

某個系統沒有現成節點時，團隊可以用以下方式快速連接。

  • REST 節點

    只要有 HTTP API，就能當作一個步驟呼叫：URL、標頭、本文與操作都在節點上設定，憑證則取自 Configure 分頁中保管的機密資訊。

  • 透過 MCP 提供代理程式

    代理程式可作為 MCP 工具使用，團隊使用的任何 MCP 用戶端都能呼叫，並適用相同的防護措施與執行記錄。

  • 以卡片設定模型

    模型的設定方式與連接器相同：一張卡片，勾選它所提供的功能。更換模型後，建立在其上的一切仍可照常運作。

關於連接系統的問題

安全團隊在 AI 代理程式接觸記錄系統之前會提出的問題。

  1. 01

    連接系統時，資料會送到哪裡？

    +

    連接器在 NeuralSeek 執行的地方運作。在自有環境中，這代表在自己的網路內。若同時自行託管模型，所有呼叫都留在內部。

  2. 02

    憑證存放在哪裡？

    +

    存放在 Configure 分頁，以具名機密資訊保管。工作流程以名稱參照機密資訊，其值保持隱藏，並從編輯器中的選單插入。

  3. 03

    代理程式除了讀取，也能寫入系統嗎？

    +

    可以，使用相同的節點。每個步驟送出與收到的內容都記在執行記錄中；已儲存的代理程式只會在 API 請求或所設排程呼叫時執行。
