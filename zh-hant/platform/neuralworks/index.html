NeuralWorks

工作空間助理， 由自己掌控的代理程式建構

NeuralWorks 協助團隊處理會議、電子郵件、文件和系統更新。每項工作都由可開啟、可編輯的 mAIstro 代理程式執行。

申請示範了解如何建構代理程式

功能

協助處理日常工作

每項工作都由一組代理程式負責，每組代理程式要做什麼，都由自己設定。

  • 會議

    為行事曆上的會議做準備，並跟進已經結束的會議。

  • 電子郵件

    整理收到的郵件，挑出需要處理的項目，並草擬回覆供寄出。

  • 文件

    以自有資料草擬並編輯文件，可在內建編輯器中編輯，或匯出為平常使用的格式。

  • 業務系統中的更新

    將自然語言的請求，轉為組織所用系統中的更新，例如工單、記錄或訊息。

工作的地方

所有代理程式集中在一個畫面

Agents 畫面依執行時機，將代理程式分為會議前與會議後。每個代理程式都有自己的開關和 Test 按鈕。

每一列是一個代理程式：它的功能、是否自行執行，以及寫入的連線。將需要的代理程式開啟即可。

由代理程式建構

每項工作都是可開啟的代理程式

NeuralWorks 的每個功能都是一個 mAIstro 代理程式。可以閱讀它的範本程式碼，在視覺化編輯器中編輯，並決定它何時執行。

以上每一項都是 mAIstro 的標準功能。NeuralWorks 就是將它們組合成一個工作日的樣子。

  • 開啟、編輯

    將代理程式載入編輯器，修改後以名稱儲存，就像團隊自己建構的任何工作流程。

    查看代理程式工作流程

  • 依排程執行

    Agent Scheduler 會在所設定的分鐘、小時、日和月份執行代理程式，讓例行工作不必有人啟動就能完成。

    閱讀 Agent Scheduler 說明

  • 由自己決定何時執行

    每個代理程式上的開關，決定它是否自行執行。其餘的則在被呼叫時執行。低於自訂的信賴度時，備援機制可以通知團隊或建立問題單。

    查看代理程式如何執行

  • 輸入時就有防護

    提示詞注入防護、不當用語過濾和個人資料遮蔽，都是代理程式在模型看到輸入之前執行的節點。

    查看防護措施

安全審查會看到什麼

CISO 可審查的安全機制

工作空間助理會接觸行事曆、收件匣、文件和業務系統。NeuralWorks 執行於 NeuralSeek 平台上，並套用平台的控管。

這些控管來自 NeuralSeek 平台，適用於每個 NeuralWorks 代理程式。

  • 執行位置

    它在平台執行的地方執行：SaaS、自有雲端帳戶、自有叢集，或完全與網際網路隔離的環境。

    了解資料可以存放在哪裡

  • 自選模型

    選擇合約要求的模型，並在設定中變更，不需要重新建構。

    了解部署方式

  • 機密資料

    個人資料會在呼叫模型之前被找出並遮蔽，使用內建模式與自訂模式。

    查看防護措施

  • 每次執行都有記錄

    每次執行都逐步記錄，團隊可以確切檢查代理程式做了什麼。

    查看記錄的內容
