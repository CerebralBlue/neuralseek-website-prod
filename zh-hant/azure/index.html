Azure 原生整合

NeuralSeek 使用的 Azure 服務

在主控台中設定的內建整合。

NeuralSeek

  • 以 Azure OpenAI 作為模型層

    支援的模型供應商，提供 GPT 系列模型。設定時選擇模型，也可為代理程式的每個步驟各選不同的模型，日後再從設定變更。

  • 以 Azure AI Bot Service 作為虛擬客服

    機器人答不出問題時，NeuralSeek 會依據知識庫回答。整理過的回答可匯出到機器人，來源文件變動時，往返監控會加上標記。

  • 在代理程式內使用 SharePoint

    代理程式的步驟可使用您提供的租用戶、網站與用戶端憑證，列出、下載或上傳 SharePoint 網站中的檔案，讓 SharePoint 文件進入具備治理機制的工作流程。

  • 現有的知識庫

    文件搜尋可用 ElasticSearch 與 OpenSearch，向量搜尋可用 Pinecone 與 Milvus，在自有 Azure 環境中都受到支援。

代理程式內部

把 Microsoft 服務當作代理程式的步驟

把 Microsoft 服務以步驟加入代理程式，設定憑證與範圍，每次執行都會記錄。

Azure Blob List Containers列出 Azure Blob Storage 帳戶中的容器，並把清單回傳給工作流程。

SharePoint List Files列出 SharePoint 網站中的檔案，租用戶、網站與用戶端憑證在節點上設定。相關節點可下載與上傳。

Email (Outlook)從工作流程的步驟透過 Outlook 寄送郵件，讓代理程式的回答能以郵件送出。

模型層中的 Azure 模型

依自己的方式使用 Azure 模型

在設定中把 Azure 提供的 GPT 模型加成一張卡片，選擇它負責的功能，也可並列加入第二家供應商。價格或模型有變時，只要更新設定，代理程式就能持續運作。

資安審查的回答

給資安審查的簡短回答。

  1. 01

    資料有加密嗎？

    +

    有，傳輸中與靜態儲存時都會加密。往來服務的所有資料都透過 TLS 加密，儲存的資料也都加密。

  2. 02

    我們的資料會用來訓練任何東西嗎？

    +

    不會。NeuralSeek 與其再受託處理者都不會以客戶資料訓練模型或系統，產生的回答歸客戶所有。

  3. 03

    請求中的個人資料會如何處理？

    +

    被標示為個人資料的內容，會依您設定的動作處理：標記、遮蔽、隱藏或刪除。為了個人化回答而帶有個人資料的請求，也以相同方式處理。
