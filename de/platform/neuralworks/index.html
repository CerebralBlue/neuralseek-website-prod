NeuralWorks

Ein Arbeitsassistent aus Agenten, die Sie steuern

NeuralWorks unterstützt Ihr Team bei Meetings, E-Mails, Dokumenten und Updates in Ihren Systemen. Jede Aufgabe läuft auf mAIstro-Agenten, die Sie öffnen und bearbeiten können.

Demo anfordernAgentenerstellung ansehen

Was es tut

Hilfe bei der Arbeit eines normalen Tages

Jede Aufgabe ist eine Gruppe von Agenten, und Sie konfigurieren, was jede Gruppe tut.

  • Meetings

    Meetings in Ihrem Kalender vorbereiten und vergangene Meetings nachbereiten.

  • E-Mail

    Eingehende E-Mails sortieren, hervorheben, was Sie betrifft, und Antworten entwerfen, die Sie selbst senden.

  • Dokumente

    Dokumente aus Ihren eigenen Daten entwerfen und bearbeiten, im integrierten Editor oder exportiert in das Format, mit dem Sie arbeiten.

  • Updates in Ihren Geschäftssystemen

    Eine Anfrage in natürlicher Sprache in ein Update in den Systemen Ihres Unternehmens umsetzen, etwa ein Ticket, einen Datensatz oder eine Nachricht.

Wo Sie arbeiten

Alle Agenten auf einem Bildschirm

Der Bildschirm Agents gruppiert Agenten danach, wann sie laufen: vor oder nach einem Meeting. Jeder hat einen eigenen Schalter und eine Schaltfläche Test.

Jede Zeile ist ein Agent: was er tut, ob er selbstständig läuft und in welche Verbindung er schreibt. Schalten Sie die ein, die Sie brauchen.

Aus Agenten zusammengesetzt

Jede Aufgabe ist ein Agent, den Sie öffnen können

Jede Funktion von NeuralWorks ist ein mAIstro-Agent. Sie können seinen Template-Code lesen, ihn im visuellen Editor bearbeiten und festlegen, wann er läuft.

Jede davon ist eine Standardfunktion von mAIstro. NeuralWorks zeigt, wie sie zusammengesetzt einen Arbeitstag abdecken.

  • Öffnen und bearbeiten

    Laden Sie einen Agenten in den Editor, ändern Sie ihn und speichern Sie ihn unter einem Namen, wie jeden Workflow, den Ihr eigenes Team erstellt.

    Agenten-Workflows ansehen

  • Nach Zeitplan ausführen

    Der Agent Scheduler führt einen Agenten zu den Minuten, Stunden, Tagen und Monaten aus, die Sie festlegen. So laufen wiederkehrende Aufgaben, ohne dass jemand sie startet.

    Mehr zum Agent Scheduler lesen (auf Englisch)

  • Läuft, wann Sie es entscheiden

    Ein Schalter an jedem Agenten legt fest, ob er selbstständig läuft. Die übrigen laufen, wenn Sie sie aufrufen. Unter einer Konfidenzstufe, die Sie festlegen, kann ein Fallback ein Team benachrichtigen oder ein Ticket anlegen.

    Agentenausführung ansehen

  • Schon am Eingang geschützt

    Schutz vor Prompt-Injection, ein Schimpfwortfilter und das Maskieren personenbezogener Daten sind Knoten, die ein Agent ausführt, bevor ein Modell die Eingabe sieht.

    Guardrails ansehen

Im Produkt

Ein Agent, vom Kalender bis zur Foliensammlung

Der Agenten-Editor, oben die Schritte des Agenten, darunter der Ausgabebereich.

Der Agent aktualisiert einen Kalendertermin, sendet eine E-Mail, ruft das Modell auf und erstellt eine Foliensammlung. Jeder Schritt ist im Editor sichtbar und wird bei der Ausführung protokolliert.

Was die Sicherheitsprüfung sieht

Sicherheit, die Ihr CISO prüfen kann

Ein Arbeitsassistent arbeitet mit Ihrem Kalender, Ihrem Postfach, Ihren Dokumenten und Geschäftssystemen. NeuralWorks läuft auf der NeuralSeek-Plattform und erhält deren Kontrollen.

Diese Kontrollen stammen aus der NeuralSeek-Plattform und gelten für jeden NeuralWorks-Agenten.

  • Wo es läuft

    NeuralWorks läuft dort, wo die Plattform läuft: als SaaS, in Ihrem eigenen Cloud-Konto, auf Ihrem eigenen Cluster oder vollständig isoliert ohne Internetverbindung.

    Speicherorte Ihrer Daten ansehen

  • Das Modell Ihrer Wahl

    Wählen Sie das Modell, das Ihre Verträge verlangen, und wechseln Sie es in der Konfiguration, ohne Neuerstellung.

    Bereitstellung ansehen

  • Sensible Daten

    NeuralSeek findet und maskiert personenbezogene Daten vor dem Modellaufruf, mit integrierten und eigenen Mustern.

    Guardrails ansehen

  • Ein Protokoll jeder Ausführung

    Jede Ausführung wird Schritt für Schritt protokolliert, sodass Ihr Team genau prüfen kann, was ein Agent getan hat.

    Protokollierte Daten ansehen
