Guardrails

Hunderte von Guardrails. Integriert und individuell anpassbar.

Schützen Sie jede KI-Antwort vom ersten Tag an. NeuralSeek deckt Prompt-Injection, sensible Daten, Genauigkeit und Tonalität ab. Jeder Guardrail lässt sich an Ihre Richtlinien anpassen, Governance-Dashboards und Berichte sind integriert.

So funktioniert es

Jede Antwort wird von Anfang bis Ende geprüft

Jeder Schritt läuft der Reihe nach, und jeder wird protokolliert.

  1. 01

    Angriffe blockieren

    NeuralSeek bewertet jede Frage auf Prompt-Injection. Verdächtige Formulierungen werden entfernt, Fragen mit hohem Risiko ganz blockiert. Dazu kommen auf Wunsch Ihre eigene Liste verbotener Wörter und ein Filter für Schimpfwörter.

  2. 02

    Sensible Daten schützen

    NeuralSeek findet personenbezogene Daten, bevor sie das Modell erreichen. Sie legen pro Thema fest, ob sie markiert, maskiert, ausgeblendet oder gelöscht werden.

  3. 03

    Nach Thema routen

    Jede Frage wird einem Thema zugeordnet, damit eine Abrechnungsfrage und eine klinische Frage unterschiedlichen Regeln folgen können.

  4. 04

    Steuern, was die KI liest

    Sie entscheiden, welche Dokumente das Modell nutzen darf, wie aktuell sie sein müssen und wie viele es liest.

  5. 05

    Dem Modell Grenzwerte setzen

    Wählen Sie für jeden Schritt das Modell und seine Grenzwerte, damit eine schnelle Prüfung und eine ausführliche Antwort jeweils die passenden Einstellungen erhalten.

  6. 06

    Jede Antwort prüfen

    NeuralSeek bewertet jede Antwort anhand Ihrer Quellen. Schwache Antworten erhalten eine Warnung oder Ihre eigene Antwort, Sätze ohne Beleg lassen sich entfernen.

  7. 07

    Gesprächsspeicher steuern

    Legen Sie fest, wie viel von einem Gespräch das Modell sieht, damit sich keine sensiblen Daten ansammeln.

  8. 08

    Vollständiges Audit-Protokoll

    Jede Frage, Antwort und Bewertung wird protokolliert, und Sie können alles an Ihre eigenen Systeme senden.

In Ihren Agenten

Guardrails in jeden Agenten einbauen

Fügen Sie dieselben Guardrails als Schritte in jeden Agenten ein. In diesem Beispiel wird ein Support-Ticket auf Angriffe, Schimpfwörter und personenbezogene Daten geprüft und bei Bedarf gestoppt, bevor es das Modell erreicht.

Genauigkeit

Mehrstufige Prüfungen gegen Halluzinationen

Übersieht eine Prüfung etwas, fängt die nächste es ab. Sie sehen immer, welche Prüfung eine Antwort gestoppt hat.

  1. 01

    Antworten beim Thema halten

    Antworten stammen nur aus Ihrer Wissensdatenbank, dazu aus einem Standarddokument, das Sie für alles schreiben, was sie nicht abdeckt. Das Modell bleibt bei den Themen, die Sie wählen.

  2. 02

    Sätze ohne Beleg entfernen

    NeuralSeek prüft jeden Satz anhand Ihrer Quellen, bevor die Antwort ausgegeben wird.

  3. 03

    Eine Mindestkonfidenz festlegen

    Antworten unter Ihrem Mindestwert werden durch Ihre eigene Antwort ersetzt und protokolliert.

  4. 04

    Antworten mit niedriger Konfidenz weiterleiten

    Eine Antwort mit niedriger Konfidenz kann einen Workflow starten. Ein Fallback-Agent kann ein Team benachrichtigen, ein Ticket anlegen, die Antwort umschreiben oder an einen anderen Agenten übergeben.

Datenschutz

Sensible Daten nach Ihren Regeln schützen

NeuralSeek findet personenbezogene Daten, Sie entscheiden, was damit geschieht. Legen Sie die Aktion pro Thema fest, um eine Kennung in einem Kontext zu maskieren und in einem anderen zu blockieren.

  • Zwei Erkennungsebenen

    Musterfilter erkennen Formate wie Konto- und Ausweisnummern. Ein KI-Filter, trainiert mit einem einzigen Beispielsatz, erkennt, was Muster übersehen.

  • Freigabelisten für unbedenkliche Begriffe

    Markieren Sie Begriffe, die Ihr Team als unbedenklich kennt, oder vertrauen Sie Wörtern aus Ihren eigenen Dokumenten, und lassen Sie jede Erkennung eingeschaltet.

  • Anmeldedaten als Secrets

    Passwörter und API-Schlüssel, die ein Agent nutzt, liegen als Secrets vor. Wer den Agenten liest, sieht sie nicht.

  • Erkennung und Schwärzung personenbezogener Daten

    Personenbezogene Daten markieren, maskieren, ausblenden oder löschen, je nach Thema konfiguriert.

  • Vollständiges Audit-Protokoll

    Jede Frage, Antwort, Bewertung und Änderung an Einstellungen wird mit Zeitstempel und Urheber protokolliert. Exportieren Sie das Protokoll nach S3, Splunk oder Datadog.

Fragen von Sicherheitsteams

Kurze Antworten für Ihre Sicherheitsprüfung.

  1. 01

    Kann ein Entwickler die Guardrails umgehen, indem er das Modell direkt aufruft?

    +

    Jeder Aufruf an NeuralSeek durchläuft dieselben Prüfungen, egal welche App ihn sendet. Betreiben Sie NeuralSeek in Ihrer eigenen Umgebung, und Ihre Netzwerkkontrollen entscheiden, was das Modell sonst noch erreicht.

  2. 02

    Blockieren strenge Guardrails nützliche Antworten?

    +

    Sie legen die Strenge pro Thema fest, sodass eine allgemeine und eine regulierte Frage jeweils ihre eigene Stufe haben. Stimmen Sie die Guardrails anhand Ihrer eigenen Ergebnisse ab.

  3. 03

    Was geben wir einem Prüfer konkret in die Hand?

    +

    Ein vollständiges Protokoll jeder Frage, Antwort und Bewertung, das Sie an Ihre eigenen Systeme senden und so wiedergeben können, wie es ablief. Änderungen an Einstellungen zeigen, wer sie vorgenommen hat, und lassen sich rückgängig machen.
