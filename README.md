# NeuralSeek

NeuralSeek is an enterprise AI platform to build and run AI agents and accurate answers on your
own data, with guardrails, governance and audit trails built in. Use it as consumption-based SaaS
on Azure, AWS or IBM Cloud, or run it with an unlimited on-prem license on your own
infrastructure. Compliance: SOC 1, SOC 2 Type II and HIPAA.

## The platform

| Part | What it does |
|---|---|
| **Seek** | Answers from your knowledge base, with confidence scores and the source behind each answer. |
| **mAIstro** | Build multi-step agents in NTL (NeuralSeek Template Language) and choose a model per step. |
| **Guardrails** | Hundreds of guardrails, built in and ready to customize. |
| **Governance** | Answer quality, cost and usage, with logs for every answer and agent run. |
