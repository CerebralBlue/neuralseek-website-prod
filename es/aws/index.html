Integraciones nativas con AWS

Los servicios de AWS que usa NeuralSeek

Integraciones incluidas en el producto, para usar NeuralSeek sin salir de AWS.

NeuralSeek

  • Amazon Bedrock · modelos

    Un proveedor de modelos compatible. Elige un modelo de Bedrock al configurar NeuralSeek, o uno distinto para cada paso de un agente, y cámbialo después en la configuración.

  • Kendra y Bedrock · conocimiento

    Bases de conocimientos compatibles para búsqueda vectorial administrada por AWS, que se encarga de la segmentación, los embeddings y la indexación. Los filtros de Kendra limitan cada consulta a lo que cada usuario puede ver.

  • Amazon Lex · agente virtual

    Cuando un bot de Lex no tiene respuesta para una pregunta, NeuralSeek responde a partir de tu base de conocimientos. Las respuestas revisadas se exportan a Lex y se marcan cuando cambian sus fuentes.

  • Amazon S3 · archivos

    Un paso del agente lee un archivo de un bucket o escribe uno de vuelta, con el bucket, la región y las credenciales de IAM que le des.

Dentro de un agente

Servicios de AWS como pasos de un agente

Agrega un servicio de AWS a un agente como un paso y define el servicio, las credenciales y el alcance. Estas son las tarjetas que ve tu equipo técnico en la consola.

S3 Read FileLee un objeto de un bucket de S3 y lo trae al flujo de trabajo, con el bucket, la región y las claves de IAM definidos en el nodo. S3 Write File lo escribe de vuelta.

RedshiftSe conecta a un almacén de datos de Redshift, ejecuta una consulta SQL y devuelve los datos como oraciones o en CSV.

Bedrock en la capa de modelos

Usa los modelos de Bedrock a tu manera

Agrega un modelo de Bedrock como tarjeta en la configuración, elige las funciones que cumple y, si quieres, agrega otro proveedor a su lado. Cuando cambian los precios o los modelos, actualizas la configuración y tus agentes siguen funcionando.

Respuestas para la revisión de seguridad

Respuestas breves para tu revisión de seguridad.

  1. 01

    ¿Los datos están cifrados?

    +

    Sí, en tránsito y en reposo. Todo lo que llega al servicio o pasa por él va cifrado con TLS, y todo lo que se almacena también está cifrado.

  2. 02

    ¿Se usan nuestros datos para entrenar algo?

    +

    No. Ni NeuralSeek ni ninguno de sus subencargados usan datos de clientes para entrenar modelos o sistemas, y las respuestas generadas pertenecen al cliente.

  3. 03

    ¿Qué pasa con los datos personales de una solicitud?

    +

    El contenido marcado como datos personales se trata según la acción que hayas configurado: marcar, enmascarar, ocultar o eliminar. Las solicitudes que incluyen datos personales para dar una respuesta personalizada reciben el mismo tratamiento.
