Integraciones nativas con Azure

Los servicios de Azure que usa NeuralSeek

Integraciones incluidas en el producto, que configuras en la consola.

NeuralSeek

  • Azure OpenAI como capa de modelos

    Un proveedor de modelos compatible, con la familia GPT. Elige un modelo al configurar NeuralSeek, o uno distinto para cada paso de un agente, y cámbialo después en la configuración.

  • Azure AI Bot Service como agente virtual

    Cuando el bot no tiene respuesta para una pregunta, NeuralSeek responde a partir de tu base de conocimientos. Las respuestas revisadas se exportan al bot, y el monitoreo de ida y vuelta las marca cuando cambian los documentos de origen.

  • SharePoint desde un agente

    Un paso del agente puede listar, descargar o subir archivos en un sitio de SharePoint con las credenciales de tenant, sitio y cliente que le des, para que tus documentos de SharePoint alimenten un flujo de trabajo con gobernanza.

  • Las bases de conocimientos que ya usas

    ElasticSearch y OpenSearch para la búsqueda de documentos, y Pinecone y Milvus para la búsqueda vectorial, todas compatibles en tu cuenta de Azure.

Respuestas para la revisión de seguridad

Respuestas breves para tu revisión de seguridad.

  1. 01

    ¿Los datos están cifrados?

    +

    Sí, en tránsito y en reposo. Todo lo que llega al servicio o pasa por él va cifrado con TLS, y todo lo que se almacena también está cifrado.

  2. 02

    ¿Se usan nuestros datos para entrenar algo?

    +

    No. Ni NeuralSeek ni ninguno de sus subencargados usan datos de clientes para entrenar modelos o sistemas, y las respuestas generadas pertenecen al cliente.

  3. 03

    ¿Qué pasa con los datos personales de una solicitud?

    +

    El contenido marcado como datos personales se trata según la acción que hayas configurado: marcar, enmascarar, ocultar o eliminar. Las solicitudes que incluyen datos personales para dar una respuesta personalizada reciben el mismo tratamiento.
