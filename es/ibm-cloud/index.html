Integraciones nativas con IBM

Los servicios de IBM que usa NeuralSeek

Integraciones incluidas en el producto. Suma una capa de aplicación con gobernanza a watsonx, Discovery y Assistant, tal como ya los usas.

NeuralSeek

  • watsonx.ai como capa de modelos

    Un proveedor de modelos compatible. Elige un modelo de watsonx al configurar NeuralSeek, o uno distinto para cada paso de un agente, y cámbialo después en la configuración.

  • Watson Discovery y watsonx Discovery como bases de conocimientos

    Recomendadas por su ajuste de relevancia y sus consultas con filtros dinámicos, que dan prioridad a los documentos correctos y limitan cada consulta a lo que cada usuario puede ver. watsonx Discovery agrega búsqueda vectorial e híbrida.

  • watsonx Assistant como agente virtual

    Una plantilla de inicio rápido agrega la búsqueda alternativa: cuando el asistente no tiene respuesta para una pregunta, NeuralSeek responde a partir de tu base de conocimientos. Las respuestas revisadas se exportan al asistente y se marcan cuando cambian las fuentes.

  • watsonx.governance desde un agente

    Un paso del agente registra una recuperación y su respuesta en watsonx.governance, o le envía una carga útil sin procesar, para que el registro de modelos de IBM y el registro de auditoría de NeuralSeek describan la misma solicitud.

Dentro de un agente

Gobernanza en cada ejecución

Cada integración es un paso dentro de una ejecución: se elige un modelo por paso, una base de conocimientos responde y la llamada de gobernanza ocurre mientras se genera la respuesta.

watsonx.ai en la capa de modelos

Usa los modelos de watsonx.ai a tu manera

Agrega un modelo de watsonx.ai como tarjeta en la configuración, elige las funciones que cumple y, si quieres, agrega otro proveedor a su lado. Cuando cambian los precios o los modelos, actualizas la configuración y tus agentes siguen funcionando.

Respuestas para la revisión de seguridad

Respuestas breves para tu revisión de seguridad.

  1. 01

    ¿Los datos están cifrados?

    +

    Sí, en tránsito y en reposo. Todo lo que llega al servicio o pasa por él va cifrado con TLS, y todo lo que se almacena también está cifrado.

  2. 02

    ¿Se usan nuestros datos para entrenar algo?

    +

    No. Ni NeuralSeek ni ninguno de sus subencargados usan datos de clientes para entrenar modelos o sistemas, y las respuestas generadas pertenecen al cliente.

  3. 03

    ¿Qué pasa con los datos personales de una solicitud?

    +

    El contenido marcado como datos personales se trata según la acción que hayas configurado: marcar, enmascarar, ocultar o eliminar. Las solicitudes que incluyen datos personales para dar una respuesta personalizada reciben el mismo tratamiento.
